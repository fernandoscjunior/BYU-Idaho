# Overview

Cli-blog is a personal blog application that runs on the terminal.  
With it you can write your blog post and read any post you have written in Markdown format.

## Development Environment

I am using VS Code as my IDE
No AI agent or Copilot
I had to install Visual Studio 2026 Community Edition  
with C++ development libraries and Windows 11 SDK.

**Programming Languages:**
Rust
Crates: crossterm for raw terminal functionality
